# dsh-bgm

面向 DSH Web 的跨平台系统音乐状态与节奏动画插件。

插件直接采集默认系统输出，不依赖具体播放器，因此 QQ 音乐、网易云音乐、浏览器和其他应用共用同一条音频链路。原始 PCM 仅在本机原生助手的内存中计算，随后只把音量、低频、中频、高频和鼓点强度传给 DSH Web，不录音、不落盘。

它不会添加右下角播放器，也不会让最终回答参与动画；识别到官方最终正文流后会立即拆除视觉层，并忽略后续 token 的 DOM 变化。Deep Diving 和当前活动行使用两条独立音轨：Deep Diving 由低频鼓点与起音触发，动作短、重、接近音游判定反馈；Think、Read、工具与上下文注入由中高频变化和旋律瞬态触发，形成较慢的信息流编舞。流式文字完全由 React 原样绘制，不复制 glyph；真实活动行会随实时音量整体上浮最多 3px、纵向呼吸最多 1.5%，并配合独立音符、判定线与行底光带。滚动区外的文字不会进入轨道，页面与对话背景永远不会随节拍闪烁。

Deep Diving 鼓点轨继续保留“触发顺序 × 运动轨迹 × 击打手感”的约 60 种组合。稳定的信息流文字则不再使用奇偶、随机、分裂、扇形或环绕等单字轨迹，而是整行共享一条连续曲面：中间低两边高的 valley、中间高的 peak、随相位行进的 sine、连续斜坡 saw，以及从中心向两端扩散的 burst。相邻字的高度只由行内位置计算，因此始终连成完整轮廓。实测周期低于 500ms 时会提高 sine/burst 比例，低于 350ms 时一拍运行两轮相位；强 burst 还会从行中心向两侧各射一道局部短光，不进行页面闪烁。

信息流至少积累两个可靠拍间隔后才显示判定线，不再使用硬编码的默认速度；下一拍按 `lastHit + period` 预测，音符提前 `clamp(period × 0.75, 350ms, 900ms)` 从最新活动行尾飞向左侧，并在预测拍到达判定线。实时 RMS 经过快上升、慢衰减的包络后持续控制波面幅度、稳定 glyph 的 3% 呼吸、音符拖尾透明度和光迹亮度，因此无 hit 的间隔也会随音量变化。克隆字带同色彗星拖尾，由慢到快冲向判定线；GOOD/GREAT/PERFECT 命中时，音符先压扁再于 150–190ms 内猛弹开，同时只在判定点附近产生 6/8/10 个对应颜色粒子和两层同色冲击环。命中还会顿帧 45ms，但只暂停 dsh-bgm 自己的视觉动画，React 对话、滚动和页面不会冻结；环内只有低透明度径向亮斑，绝不进行白色页面闪烁。窗外 detected 只会静默重锚节拍网格，不再直接判 MISS；附近的 melodic fallback 会以降权 GOOD 结算。判定音符与活动文字统一使用中高频信息流时钟，Deep Diving 则继续独立使用低频鼓点时钟，两套节奏不在同一行叠加。信息流波面以实测 `period` 完成一轮相位：强拍幅度 18–24px，中拍 11–15px，弱拍与 fallback 仅 5–8px；所有字同一时刻压缩、弹开与回落，不再存在逐字延迟或横向漂移。命中瞬间，局部键帽和判定线会在约 8ms 内硬压、140ms 内回弹，同时产生扩散环。连续命中累积 Combo、七位分数、准确率和局部加分弹字：5 Combo 增强局部冲击，10 Combo 浮现金色描边，25 Combo 增加金色拖尾，并在 5/10/25/50 显示对应里程碑。只有预测拍超时且窗口内确实没有检测时才显示一次 MISS 并重置 Combo。极短的 Bash/Read 会在出现时立即触发一次入场乐谱，并只保留最新一行 1.6 秒，让任务完成后仍有足够时间呈现音游反馈。

最终回答流式输出结束后，如果本局至少产生过一次判定，会在原判定行附近显示 3.2 秒音游结算卡：最终七位 SCORE、S/A/B/C/D 评级、ACC、PERFECT/GREAT/GOOD/MISS 数量和最大 Combo。最终输出开始前会先保存判定行位置与本局统计，正文输出期间不显示视觉层；结算卡动画结束后才清零，新活动开始时会提前撤下旧结算并清零。音乐停止、切歌或暂停只做静默清理，不弹结算。

流式中的 Think、工具或摘要完全保留 React 原文，不建立逐字镜像，也不 mask 文字，因此 token 每约 90ms 更新时不会重启动画；这一阶段直接对活动行做不影响布局的整体合成呼吸。活动行稳定后才建立一次逐字层并恢复连续 BPM 波面。视觉层始终不改写 React 的文本节点，Markdown、复制、链接和无障碍文本仍由 DSH 官方组件负责；屏幕阅读器专用的“运行中”等隐藏状态不会被错误绘制到对话区。

## 技术栈

- DSH Host：TypeScript + Cordis
- DSH Web：React + TypeScript/TSX
- macOS Helper：Swift 6 + Core Audio Process Tap
- Windows Helper：C# / .NET 8 + WASAPI 回环采集（NAudio 2.3.0）

## 开发

```sh
git clone <repository-url> dsh-bgm
cd dsh-bgm
pnpm install
pnpm run build
```

## 安装到 DSH Web

```sh
dsh plugin --profile web add link:.
```

重启 `dsh web` 后播放系统声音，再发起一次对话即可观察对话区的逐字节奏效果。

macOS 首次启动可能请求“系统音频录制”权限。Windows 版本需要在 Windows 机器上执行一次 `pnpm run build:native`，生成自包含的原生助手。
